# ED_Urgency

**Scientific Reports (2023)** · [Read the open-access paper](https://www.nature.com/articles/s41598-023-41544-0)

Python code for predicting patient mortality in emergency departments. This repository accompanies *Improved patient mortality predictions in emergency departments with deep learning data-synthesis and ensemble models*.
